横轴 = 每任务成本（对数，越左越便宜）· 纵轴 = AA 智能指数（越上越强）· 气泡面积 = 输出 tok/s（面积正比于速度，故半径取 √） · 厂商同色细折线 = 同族同代次的档位能力线（按推理档位固定顺序：non-reasoning / minimal / low / medium / high / xhigh / max，保留分数倒挂）· 金色虚线 = Pareto 性价比前沿， 线上的点「性能与成本两轴都没被别的模型同时超过」，只有看前沿才知道该选谁。最小的那一号气泡是没测到 tok/s 的占位，不代表它最慢。 双评分 = 智能指数 / 历史参照（AA Progress），版本随载荷，缺分为 —。 虚线描边 + 外套同心环带的气泡 = 同族推估值（不是实测，环带宽度 = 参照实测散布，表格里标「估」）：同一族的其它档已测、只缺这一档时，按智能指数在相邻两档之间插值； 这些点不参与 Pareto 前沿的计算。悬停可看它是怎么推的。 中心只给一层淡色填充、外套环带的最小圆点 = 同级能力参照带（表格里标「带」）：连同族也推不出时的兜底，只给「智能指数相邻的那些实测模型跑出的速度范围」， 「沿用 MM-DD」= 这一行已被榜单撤下，按最后一次实测值留在图上（判据：现役行里没有任何一行在 指数≥、每任务成本≤、速度≥ 三项上全面优于它——换版不等于旧模型没价值，实测例：新代次指数与成本更好、 速度却从 74 tok/s 掉到 51）。缺任一项就不能用来证明"全面优于"，所以缺数据的行不会被判为被取代； 最长沿用 30 天，过期即不再沿用。 刻意不给中心值——那是别家同级能力的分布，不是这个模型的估计；同样不参与前沿，也不进任何判据。
